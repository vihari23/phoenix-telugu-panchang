My annual Telugu tithi events

Create birthdays, anniversaries, and family observances that follow a Telugu lunar date instead of the same Gregorian date each year. Dates are calculated for Phoenix sunrise.

Your privacy: Names and dates entered here are stored only in this browser, not uploaded to GitHub or any server. You can download an ICS file to import into Apple Calendar. Downloaded files do not update automatically; a private live subscription requires a separate authenticated service. A public GitHub-hosted personal feed is possible only if you explicitly approve publishing the event details.

Add a tithi event

If your original event date is within the published calendar window, choose the Gregorian date and tap “Use this date” to fill in its Telugu lunar details. Otherwise select the Telugu lunar month, fortnight, and tithi manually.
