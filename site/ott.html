Apple Calendar setup

On Mac: Calendar → File → New Calendar Subscription → paste https://vihari23.github.io/phoenix-telugu-panchang/india-ott.ics. Choose an automatic refresh frequency. On iPhone: Calendar → Calendars → Add Calendar → Add Subscription Calendar.

Details

Events appear from 8–9 AM America/Phoenix on the India release date. That hour is for calendar display, not the actual platform premiere time. Tentative or undated releases are excluded.

Source: Cinebuds public dated release listings. Dates can change. If the source cannot be retrieved, the feed falls back to its last reviewed seed and may be stale. Verify important dates directly with the streaming platform. No personal event information is published in this calendar.
